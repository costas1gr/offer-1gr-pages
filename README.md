# Offer 1gr Pages

Create a modern web design agency landing page in Greek language. The main goal is to promote website creation services. The page must include the following sections in this exact order: 1. Hero Section: Catchy title offering landing page creation, a short sub-headline, and a prominent call-to-action button. 2. Services/Benefits: Briefly explaining why a business needs a landing page. 3. Pricing Table: A section featuring 3 pricing tiers side-by-side: - "Βασικό Πακέτο" (Basic plan for quick deployment). - "Πακέτο Υποστήριξης" (Premium plan including monthly technical support). - "Επεκτάσιμο Πακέτο" (Enterprise custom plan based on client requirements). 4. FAQ Section: Frequently asked questions and clear notes about hosting, domains, and delivery times. 5. Contact & Order Form: A functional contact form that also serves as an order request form for potential clients to pick a plan and leave their details. 6. Footer: Simple footer with copyright info. Use a professional, tech-focused, and clean design style with a modern color palette like dark blue and cyan accents.
